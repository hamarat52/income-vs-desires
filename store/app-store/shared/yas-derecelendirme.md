# Yaş derecelendirmesi / Age rating

Kaynak: eski `APP-STORE-LISTELEME.md` › "Yaş derecesi anketi". Apple: "the
rating is set at the app level in the App information section and is applied
across all platforms" (App information referansı, 28.10.2026) → macOS ve iOS
için tek anket.

Uygulamada kullanıcı içeriği, sohbet, reklam, satın alma, uygulama içi
tarayıcı, konum veya sağlık içeriği yok. / The app has no user-generated
content, chat, ads, purchases, in-app browser, location or health content.

| Soru grubu / Question group | Cevap / Answer |
|---|---|
| Şiddet (çizgi film/gerçekçi/uzun süreli), korku / Violence, horror | Yok / None |
| Cinsellik, çıplaklık / Sexual content, nudity | Yok / None |
| Küfür, kaba mizah / Profanity, crude humor | Yok / None |
| Alkol, tütün, uyuşturucu; kumar; yarışma / Alcohol, tobacco, drugs; gambling; contests | Yok / None |
| Tıbbi/tedavi bilgisi; sağlık konuları / Medical or treatment info; health topics | Yok / None |
| Kullanıcı içeriği, mesajlaşma, sosyal medya / User-generated content, messaging, social media | Hayır / No |
| Reklam / Advertising | Hayır / No |
| Sınırsız web erişimi / Unrestricted web access | Hayır — uygulama web sitesi açmaz; uzantı kullanıcının kendi Safari'sinde çalışır (host app `Main.html` CSP `default-src 'self'`) / No — the app opens no websites; the extension runs in the user's own Safari |
| Ebeveyn denetimi, yaş doğrulama / Parental controls, age assurance | Hayır / No |
| Made for Kids | Hayır / No |

Beklenen sonuç / Expected result: **4+**. Apple'ın güncel anket metinleri App
Store Connect'te görülecek; tablo içerik kategorileri bazında hazırlandı
(soru metinleri birebir doğrulanmadı).
